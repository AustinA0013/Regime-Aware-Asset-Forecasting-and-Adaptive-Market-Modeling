# Regime-Aware-Asset-Forecasting-and-Adaptive-Market-Modeling
A quantitative research framework for hidden market regime detection and regime-aware asset forecasting, combining HMM-based market states with asset-level features for causal return prediction, relative-performance modeling, and cross-sectional ranking.
